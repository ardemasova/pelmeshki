# Pelmeshki 2.0 — сайт

Статичный сайт без сборки: `index.html`, `styles.css`, `main.js`, `i18n.js` и папка `frames/` с кадрами анимации.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий, например `pelmeshki`.
2. **Add file → Upload files**: загрузите файлы из корня (`index.html`, `styles.css`, `main.js`, `i18n.js`, `poster.webp`, `.nojekyll`, `README.md`) → Commit.
3. Кадры загружайте **по одной папке за раз** (GitHub принимает до 100 файлов за одну загрузку): перетащите папку `frames/d0` → Commit, потом `frames/d1` и так далее до `d7`, затем `m0`…`m7`. Папки уже разбиты по 100 файлов.
   Проще всего это делать через GitHub Desktop: там можно закоммитить всё сразу.
4. **Settings → Pages** → Deploy from a branch → `main` / `(root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/pelmeshki/`.
